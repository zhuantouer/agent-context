---
name: cross-model-review
description: Generate a review package for another model, or process review feedback.
---

If you have just completed work that needs review: run the cross-model-review skill Phase 1 to generate a review package you can paste into another model.

If you have returned with feedback from another model: run the cross-model-review skill Phase 2 to process the feedback, accept/reject each point, and apply fixes.
